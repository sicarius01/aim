# Aim Trainer

winsafe(Win32 API) 기반의 가벼운 개인용 에임 연습 프로그램입니다. 외부 GUI 프레임워크 없이
순수 Win32 + 직접 GDI 페인팅 + raw mouse input으로 동작합니다. 창 제목은 `Notes`,
외관은 VSCode 다크 그레이 톤이라 눈에 잘 띄지 않습니다.

## 기능

- **에임 영역(좌측)**: 랜덤 위치에 타깃(원)이 주기적으로 생성되고 일정 수명 후 사라집니다.
  여러 개가 동시에 떠 있을 수 있습니다.
- **초록 빈 링 커서**: 연습 중 마우스 커서는 두께 있는 초록색 빈 원(내부 비어 있음)으로 표시됩니다.
  OS 커서는 숨겨지고 에임 영역 안에 갇힙니다(ESC로 해제).
- **정확한 eDPI 감도**: raw mouse input(가속 무시)으로 커서 속도를 직접 제어합니다.
  `eDPI = DPI × 감도`. 예) DPI 800 + 감도 4.0 → eDPI 3200.
- **점수**: 타깃이 뜬 뒤 얼마나 빨리, 얼마나 중앙에 가깝게 클릭했는지로 계산합니다.

## 빌드 / 실행

```sh
cargo build --release
./target/release/aim_trainer.exe
```

요구 사항: Rust(MSVC 툴체인), Windows.

## 사용법

1. 우측 패널에서 설정값을 입력합니다.
2. **[시작]** 버튼 또는 **F2**로 연습을 시작합니다.
   - 커서가 초록 링으로 바뀌고 에임 영역에 갇힙니다.
3. 초록 링으로 타깃을 조준해 **좌클릭**합니다.
4. **ESC**(또는 F2, 또는 [정지])로 멈춥니다. 다른 창으로 전환(Alt-Tab)해도 자동으로 멈춰
   커서가 복구됩니다.

## 설정 항목

| 항목 | 설명 | 기본값 |
|------|------|--------|
| 마우스 DPI | 마우스 하드웨어 DPI | 800 |
| 감도 (sensitivity) | 게임 감도 값 | 4.0 |
| eDPI | `DPI × 감도` (자동 계산, 표시 전용) | 3200 |
| 커서 속도 배율 | 실제 게임 손맛에 맞추는 미세 보정 (1.0 = 1카운트당 1px @ eDPI 3200) | 1.0 |
| 타깃 크기 | 원의 반지름(px) | 28 |
| 생성 주기 | 새 타깃 생성 간격(ms) | 850 |
| 타깃 수명 | 생성 후 사라지기까지(ms) | 1100 |
| 최대 동시 타깃 | 화면에 동시에 떠 있는 최대 개수 | 4 |

설정은 **[시작]을 누르는 순간** 적용됩니다(연습 중에는 고정).

## 감도(eDPI) 동작 방식

2D 평면 트레이너에서 "eDPI 3200"에 해당하는 절대 픽셀 이동량은 게임/모니터마다 달라
유일한 정답이 없습니다. 이 프로그램은 다음 공식을 씁니다:

```
픽셀_이동 = 마우스_카운트 × (eDPI / 3200) × 커서_속도_배율
```

즉 eDPI에 **선형 비례**해 커서 속도가 바뀌므로 상대적인 감도 연습은 정확합니다.
실제 게임과 절대적인 손맛을 맞추려면 **커서 속도 배율**을 조정하세요.

> 정확한 연습을 위해 Windows 설정 → 마우스 → 추가 마우스 설정 → 포인터 옵션에서
> **"포인터 정확도 향상"(마우스 가속)을 끄는 것**을 권장합니다. raw input 자체는 가속의
> 영향을 받지 않지만, 평소 게임 환경과 일치시키기 위함입니다.

## 점수 계산

타깃을 맞히면:

```
정확도   = clamp(1 − (클릭~중앙 거리 / 반지름), 0, 1)      # 중앙=1, 가장자리=0
신속도   = clamp(1 − (반응시간 / 타깃수명), 0, 1)          # 즉시=1, 소멸직전=0
획득점수 = 100 × (0.25 + 0.75 × 정확도) × (0.35 + 0.65 × 신속도)
```

- 타깃 없는 곳을 클릭하면 **빗맞힘**으로 −10점(최저 0).
- 클릭하지 못하고 사라진 타깃은 **놓침**으로 집계됩니다.
- 기록: 점수 / 명중(놓침·빗맞힘) / 클릭 정확도 / 평균·최고 반응속도 / 평균 중앙 정확도.

## 구현 메모

- `winsafe` 0.0.27에는 raw input 래퍼가 없어 `RegisterRawInputDevices` / `GetRawInputData`를
  `user32.dll`에 직접 FFI(`raw` 모듈)했습니다. 마우스 이동만 raw input으로, 클릭은
  `WM_LBUTTONDOWN` + 가상 커서 좌표로 판정합니다.
- 에임 영역은 더블 버퍼링(메모리 DC + 비트맵 → `BitBlt`)으로 깜빡임 없이 그립니다.
- 다크 테마는 `WM_CTLCOLORSTATIC`/`WM_CTLCOLOREDIT` 처리로 구현했습니다.
